# voxanim-light

The light-mode videos and GIFs of [voxanim](https://github.com/rob-c/voxanim), animations that explain machine learning, drawn with NumPy. Watch them at <https://rob-c.github.io/voxanim/>.

This repository holds no code: only [releases](https://github.com/rob-c/voxanim-light/releases), one per voxanim version, each with every animation as an MP4, all the GIFs in `voxanim-gifs-light.tar`, and `SHA256SUMS`. The website streams its videos from here.

Released under the MIT licence, as voxanim is.
